# Issue

**环境**：Linux（待确认 Windows 是否同样存在）
**复现命令**：`sdt-greet --name ""`
**期望结果**：程序应以退出码 2 终止，不输出任何内容
**实际结果**：程序以退出码 0 终止，输出 `Hello, !`

---

# 提交信息

**标题**：修复空 --name 参数时未正确退出的问题

**正文**：
当 `--name` 参数为空字符串时，程序未做校验，直接输出 `Hello, !` 并以 0 退出。
修复方案：在 `main()` 中添加检查，若 `name` 为空或仅含空白字符，则调用 `sys.exit(2)`。

---

# 评审意见

**评审意见**：`cli.py` 中缺少对空 `--name` 参数的校验，导致程序在无效输入下仍正常退出并输出错误内容。建议增加输入校验逻辑，并在无效输入时返回非零退出码。

**标注**：Blocking
